# M2R 騎乘音訊模式

更新：2026-09-08

## 1. 目標

Evan 單趟機車通勤約 37 分鐘。系統在出發前產生一份預設 35 分鐘的純音訊學習清單，播放期間不要求看螢幕、觸控、拼字或自評。

騎乘模式的定位是「接觸與強化」，不是正式測驗。播放紀錄不得直接改動 FSRS rating、答對率或 mastery；需要作答的項目在停車後進入一般複習。

## 2. 預設播放流程

每個單字依序播放：

1. 提示音。
2. 英文單字。
3. 停頓 2 秒。
4. 台灣繁中主要意思。
5. 停頓 1.5 秒。
6. 英文例句；無例句時略過。
7. 停頓 3 秒，讓使用者在心中回想。
8. 再念一次英文單字。
9. 下一張。

清單以到期複習、弱項與近期新字排序；同一輪避免相鄰重複。預設 35 分鐘，可在出發前選 15、25、35 分鐘。實際張數依例句長度及語速動態計算，不以固定張數硬塞。

## 3. 騎乘安全限制

- 所有設定與「開始播放」必須在出發前完成。
- 播放中不顯示需要回應的題目，也不要求按「會／不會」。
- 不提供行進中的文字輸入、滑動選卡或視覺倒數。
- 中斷、錯誤或播完時不彈出需要立即處理的對話框。
- 音量由使用者在出發前調整，介面提醒保留環境聲；功能不鼓勵以降噪完全遮蔽交通聲。
- 法規與安全驗收以「行駛中不手持、不操作裝置」為底線。

## 4. 第一版：免費瀏覽器 MVP

使用瀏覽器 Web Speech API 的 SpeechSynthesis，在裝置端朗讀既有單字、中文意思與例句：

- 不上傳語音。
- 不需要 Gemini、Google Cloud Text-to-Speech 或新的付費 API。
- 開始播放必須由使用者點擊一次，以符合行動瀏覽器自動播放限制。
- 支援選擇可用英語／中文聲音、語速、停頓與重複次數。
- 嘗試使用 Screen Wake Lock 讓頁面在騎乘期間保持啟用；Wake Lock 失效時顯示可理解的狀態。
- 先載入整份清單後才允許開始，避免途中因網路不穩而要求操作。
- 不承諾鎖定螢幕或切到背景後持續播放；此能力必須以 Evan 的實際手機與瀏覽器驗收。

### UI

出發前只提供：

- 時長：15／25／35 分鐘，預設 35。
- 語速：0.8×／0.9×／1.0×，預設 0.9×。
- 內容：到期優先／弱項優先／混合，預設混合。
- 「開始騎乘模式」大按鈕。
- 播放前安全提醒與一次確認。

播放畫面只保留大尺寸「暫停／繼續」與「結束」；設計目的不是供行進中操作，而是停妥後容易控制。

## 5. 第二版：真正背景音訊

若實機驗收證明螢幕鎖定、背景播放、藍牙安全帽耳機媒體鍵是必要條件，改用預先生成的音訊檔與標準 HTML audio／Media Session，或升級為 PWA／原生 App。

進入第二版前必須先決定：

- TTS 供應商、聲音授權與每月成本上限。
- 音訊是否保存在 Google Drive／Cloud Storage，以及保留期限。
- iOS、Android 與安全帽藍牙設備的目標組合。
- 離線下載、儲存空間與刪除機制。

未核准供應商及成本前，不啟用付費 TTS，也不把單字內容送往新的外部服務。

## 6. 資料與排程

新增的播放事件使用獨立事件類型，例如：

- session_id
- word_id
- event_type = audio_exposure
- played_at
- completed
- source = riding_mode
- client_event_id（冪等）

audio_exposure 只供統計與後續推薦使用，不等同 review。只有在一般學習介面完成可判定的作答或自評，才更新 FSRS 狀態。

## 7. 驗收條件

1. 出發前一次操作即可連續播放整份清單。
2. 35 分鐘清單會自行結束，不需要途中操作。
3. 英文與中文使用正確語言的裝置聲音；缺少指定聲音時能安全降級。
4. 來電、導航播報或藍牙斷線後，不會重複寫入學習紀錄。
5. Android Chrome 與 iPhone Safari 分開實測並記錄：前景播放、螢幕休眠、鎖定畫面、切換 App、來電／導航中斷。
6. 播放紀錄不改變答對率、mastery 或 FSRS rating。
7. 沒有外部 TTS 時，第一版不產生新增 API 費用。

## 8. 里程碑位置

- M2R-A：隨 M2 快速預習交付瀏覽器音訊 MVP。
- M2R-B：在 M2R-A 實機驗收後決定是否進入，不能以推測取代手機測試。
- M3：把停車後的弱項作答接回正式複習。
- M4：只有正式作答更新 FSRS；音訊接觸可作為排序輔助訊號，但不得直接當作記憶成功。
