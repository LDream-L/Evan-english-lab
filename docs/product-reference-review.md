# 產品參考評估｜刷刷庫與 Parroto

更新：2026-09-07

## 結論

Evan TOEIC Lab 不應照抄任何一款 App，而是組合兩種互補流程：刷刷庫提供 TOEIC 題型、詳解與錯題管理的參考；Parroto 提供真實情境、聽寫／跟讀、點字收錄與 SRS 回流的參考。Vocabulary V1 仍先完成可靠的單字資料、複習與排程；聽說功能採漸進式加入，不在目前階段導入真人社群或雲端語音評分。

## 可驗證資料來源

- [Parroto 官方首頁](https://parroto.app/zh-TW)：列出聽寫、跟讀、情境詞彙、真人口說配對、遊戲及 IELTS／TOEIC 模考。
- [Parroto 詞彙頁](https://parroto.app/zh-TW/vocabulary)：列出音標、解釋、例句、音檔、情境點字與間隔重複。
- [Parroto 跟讀頁](https://parroto.app/zh-TW/shadowing)：列出影片課程、AI 字幕／程度分類、錄音回饋、弱項複習與進度追蹤。
- [Parroto 定價頁](https://parroto.app/zh-TW/pricing)：免費方案宣稱包含 1,000+ 課程、聽寫、跟讀與基本進度；Premium 主要增加 Pro 詞彙牌組、無廣告及優先支援，採指定期間一次性付款。
- [台灣 App Store 頁面](https://apps.apple.com/tw/app/parroto-shadowing-dictation/id6752111996)：列出聽寫、跟讀、AI 發音／語調回饋、SRS 與每日 5–10 分鐘練習。

上述來源可確認產品目前如何描述與提供功能；官方成效百分比、評論數與使用者心得屬廠商或商店頁面呈現，未經本專案獨立實驗，因此不拿來推定實際學習成效。

## 功能拆解與決策

| Parroto 功能 | 對 Evan 的價值 | 決策 | 排程 |
|---|---|---|---|
| 真實影片／短內容 | 單字不脫離原句，能同時建立聽力線索 | 採用概念；先從文章必要短句與合法音訊開始 | M2 |
| 聽寫 | 可測出「看得懂但聽不出」與拼字弱點 | 採用最小版；先做短句文字比對 | M3 候選，v1.0 驗收決定是否啟用 |
| 跟讀 | 讓單字由辨識進入輸出 | 採用播放、錄音與自我回聽；AI 評分延後 | Vocabulary v1.0 後 |
| 情境中點字收錄 | 降低文章／影片到單字卡的操作成本 | 採用；接到既有文章候選與來源追蹤 | M1A／M2 |
| SRS 與錯誤回流 | 將單字、拼字與聽錯集中到同一記憶排程 | 採用；使用本專案 FSRS adapter 與弱項佇列 | M3／M4 |
| 短時單元與進度 | 適合每日有限時間，降低啟動阻力 | 採用；由 `daily_minutes` 與 session 快照控制 | M2～M5 |
| 遊戲 | 可增加重複練習意願 | 延後；先驗證核心複習是否穩定 | v1.0 後 |
| 真人語音配對／社群／排行榜 | 對個人 TOEIC 工具不是必要能力，且增加安全與維運成本 | 不納入目前計畫 | 不排程 |
| IELTS／TOEIC 完整模考 | 有後期價值，但題庫權利、計分校準與內容維護成本高 | 延後且只能用自建或合法授權題目 | TOEIC Question Bank 之後 |
| AI 發音與語調評分 | 可能提供細緻回饋，但涉及錄音傳輸、方言偏誤、費用與誤判 | 不進 Vocabulary V1；先做供應商、隱私與成本評估 | Shadowing V1 前 |

## 更新後的學習閉環

```text
文章／合法音訊
→ 候選單字與來源短句
→ 快速預習與句中選字
→ EN→ZH／ZH→EN／拼字
→ 可選短句聽寫
→ 錯字與聽錯回流弱項
→ FSRS 排程與進度
```

## 不複製與不提前實作的邊界

- 不擷取 Parroto 或刷刷庫的題目、逐字稿、影音、翻譯、牌組、詳解、圖片、介面資產或付費內容。
- 不把廠商宣稱的改善比例當成產品驗收標準。
- 不因 Parroto 功能多，就打斷目前 M1A → M2 → M3 → M4 的依賴順序。
- 不在未決定資料去向與保存期限前，把 Evan 的錄音傳到第三方 AI。
- 不建立真人配對、聊天、排行榜與獎勵兌換；這些與私人單人系統的目前目標不符。

## 更新後的優先順序

1. 修復並完成 M1A 線上部署，保證文章候選、來源短句與補全佇列可用。
2. M2 完成快速預習、來源短句、句中選字與瀏覽器發音。
3. M3 完成核心三題型與錯誤回流，再以小型驗收決定是否啟用短句聽寫。
4. M4 接入 FSRS，使單字、拼字與聽寫弱項共用排程。
5. Vocabulary v1.0 穩定後，才建立 Context Listening／Dictation V1 與 Shadowing／Pronunciation V1。
